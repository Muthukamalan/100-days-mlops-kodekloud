# Load Model from Registry with Custom Preprocessing

## Problem

The xFusionCorp Industries deployment team requires a batch-prediction wrapper for the registered fraud-detector champion model, which should include custom preprocessing, prior to the model being made available to downstream services. A pyfunc wrapper skeleton has already been prepared. Your objective is to develop the preprocessing step and implement the necessary MLflow plumbing to load the champion model and execute the batch prediction.

1. The MLflow tracking server is already running on port `5000`. The MLflow UI button at the top of the lab can be opened to view the dashboard; the Models tab shows `fraud-detector` registered with a `champion` alias on version 1.

2. Open `/root/code/predict_with_preprocessing.py` in the VS Code editor. The `ScaledPredictor` constructor and its pyfunc `.predict()` signature are provided, as are the `MODEL_URI / INPUT_CSV / OUTPUT_CSV` constants (do NOT change the constants or the class and method signatures). Three # TODO blocks remain:

    - TODO 1: Inside `ScaledPredictor.predict()`, scale the input array with the wrapper's per-column mean and std `((X - self.mean) / self.std)`, then return the inner model's predictions on the scaled array.
    - TODO 2: Load the `champion` version of `fraud-detector` from MLflow's Model Registry into a variable named `inner_model`. `MODEL_URI` is already set to `models:/fraud-detector@champion`.
    - TODO 3: Run the batch prediction over the pre-staged inputs, attach the predictions as a new prediction column on the inputs DataFrame, and write the result to OUTPUT_CSV (/root/code/predictions.csv) with index=False.

3. After all three TODOs are completed, run the script once:

   ```bash
   python3 /root/code/predict_with_preprocessing.py
   ```

The end state must include:
    - A file at /root/code/predictions.csv with a header row.
    - A prediction column in that CSV.
    - The number of prediction rows equal to the number of input rows in /root/code/data/inputs.csv (ten).
